# Embrapa Cenargen — Front-end

Repositório responsável pelo desenvolvimento da **interface web do Sistema de Gestão de Campos Experimentais da Embrapa Cenargen (CVGWeb)**.

## Sobre o projeto

Este repositório concentra os componentes responsáveis pela **interface e interação dos usuários com o sistema**, proporcionando uma experiência visual organizada para o gerenciamento dos campos experimentais e casas de vegetação do Cenargen.

O front-end será desenvolvido utilizando **HTML, CSS e TypeScript**, seguindo os protótipos e requisitos definidos ao longo do projeto.

A aplicação terá como objetivo apresentar as informações de forma clara e facilitar atividades como consulta dos espaços experimentais, visualização de sua disponibilidade, acompanhamento de reservas e acesso às demais funcionalidades disponibilizadas pelo sistema.

## Principais responsabilidades

O front-end será responsável por:

* Construção das páginas e componentes da aplicação;
* Implementação da interface visual do sistema;
* Navegação entre as diferentes funcionalidades;
* Exibição dos espaços experimentais por meio de uma interface baseada em mapa;
* Apresentação da disponibilidade dos espaços;
* Interfaces para gerenciamento de pesquisadores, projetos e espaços;
* Interfaces relacionadas ao registro e acompanhamento de reservas;
* Exibição de informações e relatórios;
* Comunicação com o back-end para obtenção e envio de dados;
* Implementação de comportamentos e validações necessárias no lado do cliente.

## Tecnologias

* **HTML** — estrutura das páginas;
* **CSS** — estilização e organização visual;
* **TypeScript** — lógica e comportamento da aplicação.

## Integração

O front-end será desenvolvido de forma independente do back-end, realizando a comunicação com a API disponibilizada pelo repositório de back-end.

Dessa forma, a interface poderá consumir os dados referentes aos pesquisadores, projetos, espaços experimentais, reservas e demais informações necessárias para o funcionamento do sistema.

## Objetivo do repositório

Este repositório tem como finalidade centralizar o desenvolvimento da camada de apresentação do **CVGWeb**, permitindo que a interface seja construída, testada e evoluída de forma independente, mantendo uma separação clara entre a apresentação e as regras de negócio da aplicação.
